# Feature-impact data request — draft, not sent

Subject: Evidence and data on game-inspired features in citizen science

Hello,

My sub-thesis examines how game-inspired features influence engagement,
learning, and data utility across Eterna, Zooniverse, EyeWire, and Foldit.

Are there documented experiments, feature rollouts, or withdrawals that could
support an evaluation of a specific feature, such as feedback, progression,
leaderboards, achievements, challenges, or collaboration tools?

For a feasible case, it would help to obtain:

- Feature dates/versions, eligibility, assignment or comparison conditions,
  actual exposure if available, and other changes made at the same time.
- Scientific activity measures before and after exposure, ideally linked by
  stable pseudonymous IDs, with clear follow-up and coverage definitions.
- Learning assessments or held-out skill/transfer measures, if collected.
- Independent scientific validation, quality/completeness, usable-output or
  review-effort measures, including how those measures were constructed.
- Known limitations, such as task changes, publicity, outages, missing records,
  anonymous contributions, and inclusion of staff, bots, or tutorials.

Aggregate tables, existing reports, or a supported research export would be
welcome. Names, contact details, and profile biographies are not required.
We would acknowledge the source and follow the applicable data-use terms.

If such data are unavailable, documentation of the feature history and relevant
evaluation publications would still help the evidence inventory.

Thank you.
